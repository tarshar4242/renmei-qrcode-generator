# QRCode 產生器 教案設計

## 一、教材定位

這是一個單檔 HTML 的 QRCode 產生器示範教材。學員只要輸入網址，就能即時看到 QRCode，並下載成 PNG 圖片。整個作品不需要後端，適合用來教初學者理解前端互動、事件監聽、即時預覽與檔案下載。

## 二、教學對象

- 前端初學者
- 想快速做出實用小工具的人
- 想用 AI 協作完成單頁作品的入門學員

## 三、學習目標

完成本教案後，學員應能：

- 理解單檔 HTML 如何同時整合 `HTML`、`CSS`、`JavaScript`
- 做出「輸入後即時更新畫面」的互動效果
- 理解 QRCode 的基本應用情境
- 實作圖片下載功能
- 知道如何把靜態頁面部署到 GitHub

## 四、先備知識

- 會開啟瀏覽器查看 HTML 檔案
- 對 `HTML` 標籤、`CSS` 樣式、`JavaScript` 基本語法有初步概念
- 知道網址 `URL` 是什麼

## 五、教材檔案說明

- `index.html`：主程式，包含介面、樣式、QRCode 生成與下載功能
- `README.md`：本教案設計與使用說明
- `.gitignore`：避免把素材與系統檔推到 GitHub

## 六、課程流程建議

### 1. 導入

先讓學員思考：為什麼很多活動、表單、菜單、付款頁面都會提供 QRCode？

可用生活例子帶入：

「如果今天要把一個網址快速分享給很多人，直接貼連結很長，但只要把它轉成 QRCode，別人手機一掃就能打開。」

### 2. 拆解作品功能

帶學員先看成品，再拆成三個核心任務：

- 輸入網址
- 立即生成 QRCode
- 下載 QRCode 圖片

### 3. 介面結構教學

說明 `index.html` 中：

- 輸入欄位負責接收網址
- 預覽區負責顯示 QRCode
- 按鈕負責下載與清空

### 4. 互動邏輯教學

重點示範：

- `input` 事件如何做到即時更新
- 如何先檢查內容是否像網址
- 沒有輸入協定時，如何自動補上 `https://`

### 5. 下載功能教學

帶學員理解：

- QRCode 先被畫到 `canvas`
- 再把 `canvas` 轉成 `PNG`
- 透過下載連結讓瀏覽器存檔

### 6. 發布觀念教學

讓學員知道：

- 靜態網站可以直接放到 GitHub
- 若啟用 GitHub Pages，就能變成可分享網址

## 七、課堂操作任務

### 基礎任務

- 輸入自己的網站或社群連結
- 下載生成後的 QRCode

### 進階任務

- 修改配色，做成自己的品牌風格
- 加入標題、副標題或 Logo
- 改成可以輸入任意文字，不只網址

### 挑戰任務

- 改成支援多種尺寸
- 加入錯誤提示優化
- 改成完全離線版，不依賴外部 CDN

## 八、教學重點提醒

- 學員常會把「頁面顯示」和「資料處理」混在一起，要特別說明畫面與邏輯的分工
- `input` 事件是本教材的重要入門觀念
- 下載功能雖然短，但很適合拿來講前端如何處理瀏覽器內的資料輸出

## 九、成果展示建議

可要求學員最後展示：

- 自己輸入的網址
- 生成出的 QRCode
- 成功下載的 PNG 檔
- 自己修改過的版面風格

## 十、使用方式

1. 直接在瀏覽器開啟 `index.html`
2. 在輸入框貼上網址
3. 頁面會即時生成 QRCode
4. 按下「下載 PNG」即可儲存圖片

## 十一、部署說明

若要部署到 GitHub：

1. 建立 GitHub Repository
2. 上傳 `index.html`、`README.md`、`.gitignore`
3. 啟用 GitHub Pages
4. 選擇從主分支發佈

## 十二、延伸教學方向

- 表單工具製作
- 名片頁製作
- 活動報名頁製作
- 單頁互動工具設計

這份教材的價值不只在 QRCode，而是在於它是一個非常適合初學者練習「做出一個真的能用的小工具」的案例。
